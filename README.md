# Aprov +

##  Descrição do Projeto

O Aprov+ é uma plataforma educacional desenvolvida para auxiliar estudantes na preparação para o ENEM.

O sistema reúne conteúdos organizados por disciplinas, simulados personalizados, inteligência artificial para resolução de dúvidas, correção de redações, cálculo da TRI e ferramentas de revisão, proporcionando uma experiência completa de aprendizado.

---

## Objetivo

Oferecer um ambiente único onde o estudante consiga estudar, praticar e acompanhar seu desempenho, utilizando recursos tecnológicos para tornar o aprendizado mais eficiente.

---

## Como Executar o Projeto

### Front-end

1. Clone o repositório:
```bash
git clone https://github.com/dudamssr/aprova-mais.git
```

2. Acesse a pasta do projeto:
```bash
cd aprova-mais
```

3. Abra o projeto no Visual Studio Code.

4. Execute o arquivo `index.html` utilizando a extensão **Live Server**.

### Back-end

1. Instale as dependências:
```bash
npm install
```

2. Gere o Prisma Client:
```bash
npx prisma generate
```

3. Execute as migrações:
```bash
npx prisma migrate dev
```

4. Inicie o servidor:
```bash
node server.js
```

### Mobile

1. Acesse a pasta do aplicativo Flutter.

2. Instale as dependências:
```bash
flutter pub get
```

3. Execute o aplicativo:
```bash
flutter run
```

## Funcionamento da Plataforma

1. O estudante realiza o cadastro ou login.
2. Escolhe a disciplina que deseja estudar.
3. Acessa conteúdos e banco de questões.
4. Realiza simulados personalizados.
5. Consulta a Inteligência Artificial para esclarecer dúvidas.
6. Envia redações para correção.
7. Visualiza o cálculo da TRI.
8. Utiliza flashcards e agenda para organizar os estudos.
9. Acompanha sua evolução por meio do desempenho registrado na plataforma.
